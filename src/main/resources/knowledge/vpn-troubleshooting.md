# VPN connection troubleshooting

Common symptoms include VPN authentication failures, timeouts, and inability to reach internal services.

Recommended checks:

1. Confirm the user is connected to the internet.
2. Verify the device date and time are correct.
3. Disconnect and reconnect the VPN client.
4. If the client supports it, sign out and sign back in.
5. Check whether the VPN gateway is reachable from the user's network.
6. If the user repeatedly receives authentication failures, create a HIGH-priority ticket for the identity or network support team.

Do not ask the user to share passwords or MFA codes.
